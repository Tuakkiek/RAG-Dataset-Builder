## 2 Harder EM

Consider the Bayesian network structure shown in Figure 2.

1. Write down an expression for $\operatorname* { P r } ( \mathtt { a } , \mathtt { b } , \mathtt { c } , \mathtt { d } , \mathtt { e } , \mathtt { f } , \mathtt { g } )$ using only conditional probabilities that would be stored in that network structure.

Solution:

$$
\Pr (a, b, c, d, e, f, g) = \Pr (f) \Pr (a | f) \Pr (b | f) \Pr (c | a, b) \Pr (d | c) \Pr (e | c) \Pr (g | e, d)
$$

2. We’d like to use variable elimination to compute Pr(d|b). Which variables are irrelevant? Solution:

Variables E and G are irrelevant. If we try to sum them out, we get factors that are identical to 1.

3. Using elimination order A, B, C, D, E, F, G to compute $\operatorname* { P r } ( \mathsf { d } | \mathsf { b } )$ , what factors get created? Solution:

We’ve already established that we can ignore E and G. And since we’re naming specific values d and b in our query, we really only need to sum over A, C, and F. Summing over F gives us factor

$$
f _ {1} (a, b) = \sum_ {\mathrm{F}} \Pr (f) \Pr (a | f) \Pr (b | f) .
$$

Summing over C gives us factor

$$
f _ {2} (a, b, d) = \sum_ {C} \Pr (c | a, b) \Pr (d | c) .
$$

Summing over A gives us

$$
\Pr (b, d) = \sum_ {A} f _ {1} (a, b) f _ {2} (a, b, d).
$$

To get the conditional probability we want, we first need to compute

$$
\Pr (b) = \sum_ {D} \Pr (b, d);
$$

then $\operatorname* { P r } ( \mathbf { d } | \mathbf { b } ) = \operatorname* { P r } ( \mathbf { b } , \mathbf { d } ) / \operatorname* { P r } ( \mathbf { b } )$

4. Assume variables F and C are hidden. You have a data set consisting of vectors of values of the other variables: ha, b, d, e, gi. You start with an initial set of parameters, $\theta _ { 0 } ,$ that contains CPTs for the whole network. You decide to estimate $\operatorname* { P r } ( \mathsf { f } | \mathsf { a } , \mathsf { b } , \mathsf { d } , e , \mathsf { g } )$ and Pr(c|a, b, d, e, g) separately, for each row of the table, as shown.

| A B D E G | Pr(F\|a,b,d,e,g) | Pr(C\|a,b,d,e,g) |
| --- | --- | --- |
| 0 1 0 1 10 0 0 1 10 0 0 0 10 1 0 1 10 0 0 0 1... |  |  |

Is this justified? Why or why not?

## Solution:

I should have said, above, “you decide to calculate” rather than “you decide to estimate” above, since we calculate these values directly from the data in each row and the model.

The answer is, in this case, yes, but not always. In particular, because F and C are independent given A and B, we can write

$$
\operatorname * {P r} (F, C | a, b, d, e, g) = \operatorname * {P r} (F | a, b) \Pr (C | a, b, d, e),
$$

and so it’s okay to fill in values for F and C independently given the other variables. (Note that we can save time by figuring out $\operatorname* { P r } ( \mathsf { F } | \mathsf { a } , \mathsf { b } )$ for every value of a and b, and using those values to fill in the whole column.)

If, instead, we had A and B as the hidden variables, we would have to estimate their values jointly, since they are not independent given values of all the other variables. Thus, we’d have to make a table that looked something like:

| C D E F G | A B | Pr(a,b\|c,d,e,f,g) |
| --- | --- | --- |
| 0 1 0 1 1 | 0 00 11 01 1 | .4.3.2.1 |
| 0 0 0 1 1 | 0 00 11 01 1 | .05.1.05.8 |

This table contains the conditional joint of A and B, for each actually observed data point. You could also make it more compact by collapsing all duplicate data points and counting them, as we did above.

5. Now you think of another shortcut: You decide to estimate $\operatorname* { P r } ( \mathsf { G } | \mathsf { d } , e )$ directly from the data and leave G out of the EM computations all together. Is this justified?

Solution:

Yes.

$$
\Pr (G | a, b, c, d, e, f) = \Pr (G | d, e).
$$

EM starts with some values in the CPT, and then it loops for a while, alternately

(a) estimating the counts for the missing data from the CPT, and then

(b) re-estimating the CPT given the new estimated counts for the missing data.

But, G’s CPT entry does not depend on the missing data, F and $\mathsf { G } ;$ it only depends on D and E. So, it’s ok to calculate its CPT parameters once, and then leave them out of the EM loop.

## 3 Markov Chain

Consider a 3-state Markov chain, where $\mathbb{R}(s_1) = 1, \mathbb{R}(s_2) = 3$ , and $\mathsf { R } ( \mathsf { s } _ { 3 } ) = - 1$ . The transition probabilities are given by the table below, where the entry in row $\mathsf { i } ,$ column j, is the probability of making a transition from $s _ { \mathrm { i } }$ to $s _ { \mathrm { j } }$

|  | s<sub>1</sub> | s<sub>2</sub> | s<sub>3</sub> |
| --- | --- | --- | --- |
| s<sub>1</sub> | 0.8 | 0.1 | 0.1 |
| s<sub>2</sub> | 0.2 | 0.1 | 0.7 |
| s<sub>3</sub> | 0.9 | 0.1 | 0.0 |

1. Compute the values of each state, assuming a discount factor of $\gamma = 0 . 9$

2. Compute the values with a discount factor of $\gamma = 0 . 1$

## Solution:

Writing out the full equation for the values of each state we get:

$$
\begin{array}{r c l} v _ {1} & = & 1 + 0. 8 \gamma v _ {1} + 0. 1 \gamma v _ {2} + 0. 1 \gamma v _ {3} \\ v _ {2} & = & 3 + 0. 2 \gamma v _ {1} + 0. 1 \gamma v _ {2} + 0. 7 \gamma v _ {3} \\ v _ {3} & = & - 1 + 0. 9 \gamma v _ {1} + 0. 1 \gamma v _ {2} \end{array}
$$

$\mathrm { O r } ,$ in matrix form:

$$
\left( \begin{array}{c c c} 0. 8 \gamma - 1 & 0. 1 \gamma & 0. 1 \gamma \\ 0. 2 \gamma & 0. 1 \gamma - 1 & 0. 7 \gamma \\ 0. 9 \gamma & 0. 1 \gamma & - 1 \end{array} \right) \cdot \left( \begin{array}{c} v _ {1} \\ v _ {2} \\ v _ {3} \end{array} \right) = \left( \begin{array}{c} - 1 \\ 3 \\ 1 \end{array} \right)
$$

With $\gamma = 0 . 9$ and 0.1, respectively, we find:

$$
\begin{array}{r c l} v _ {1} & = & 9. 2 6, \quad 1. 1 1 \\ v _ {2} & = & 1 0. 2 7, \quad 2. 9 9 \\ v _ {3} & = & 7. 4 2, \quad - 0. 8 7 \end{array}
$$

## 4 Markov Decision Process

Now, consider a Markov decision process with the same states and rewards as in the previous problem. It has two actions. The first action is described by the transition matrix given above. The second action is described by the following transition matrix:

|  | s<sub>1</sub> | s<sub>2</sub> | s<sub>3</sub> |
| --- | --- | --- | --- |
| s<sub>1</sub> | 0.1 | 0.1 | 0.8 |
| s<sub>2</sub> | 0.7 | 0.1 | 0.2 |
| s<sub>3</sub> | 0.9 | 0.0 | 0.1 |

Starting with a value function that is 0 for all states, perform value iteration for 10 iterations for $\gamma = 0 . 9$ . Do it again for $\gamma = 0 . 1$ . Can you see it converging faster in one case? If so, why? Can you see what the optimal policy is? How could you compute the values of the states under the optimal policy?

## Solution:

The solution can be implemented in a few lines of matlab:

```matlab
g = 0.9; %or 0.1
r = [1; 3; -1];
v = [0; 0; 0];
a1 = [0.8, 0.1, 0.1; 0.2, 0.1, 0.7; 0.9, 0.1, 0];
a2 = [0.1, 0.1, 0.8; 0.7, 0.1, 0.2; 0.9, 0.0, 0.1];
for i = 1:10,
    v = r + g*max(a1*v, a2*v);
end,
```

With γ = 0.9 and 0.1, respectively, we find after ten iterations:

$$
\begin{array}{r c l} v _ {1} & = & 6. 5 1, \quad 1. 1 1 \\ v _ {2} & = & 8. 3 5, \quad 3. 0 9 \\ v _ {3} & = & 4. 6 8, \quad - 0. 8 7 \end{array}
$$

We see that when $\gamma = 0 . 1$ , the values for each state are greater than or equal to those found in problem 3. We should expect this, since value iteration finds a global optimum; the policy of always choosing the first action would give exactly the discounted rewards found in problem 3, and the optimal policy will perform better than or equal to that.

So why isn’t this true when $\gamma = 0 . 9 7$ The algorithm hasn’t converged yet. Running for 1000 iterations, we find the values converge to:

$$
\begin{array}{r c l} v _ {1} & = & 1 0. 0 \\ v _ {2} & = & 1 1. 8 3 \\ v _ {3} & = & 8. 1 6 \end{array}
$$

These values are better than those found in problem 3 for $\gamma = 0 . 9$ . Intuitively, the algorithm converges quickly with smaller values of γ because we are putting less of an emphasis on future rewards and so don’t have to consider as many time steps to get a good estimate. Concretely, the value of future rewards decays to zero much more rapidly when $\gamma = 0 . 1$

To compute the optimal policy, it is only necessary to see which action gives the highest expected value at each state once value iteration has converged. For this problem, the optimal actions are 1, 2, 1, for states $s _ { 1 } ,   s _ { 2 } ,$ and $s _ { 3 }$ respectively. $\mathrm { S o } ,$ to compute the optimal values exactly we can treat this problem as a Markov Chain with transition probabilities:

|  | s<sub>1</sub> | s<sub>2</sub> | s<sub>3</sub> |
| --- | --- | --- | --- |
| s<sub>1</sub> | 0.8 | 0.1 | 0.1 |
| s<sub>2</sub> | 0.7 | 0.1 | 0.2 |
| s<sub>3</sub> | 0.9 | 0.1 | 0.0 |

Solving this system as in the previous problem will produce the same values as value iteration.

## 5 At the Races, again

You go to the horse races, hoping to win some money. Your options are to:

• Bet \$2 on Moon. You think that he’ll win with probability 0.7. If he wins, you’ll get back \$4. If he loses, you’ll get back nothing.

• Bet \$2 on Jeb. You think that he’ll win with probability 0.2. If he wins, you’ll get back \$22. If he loses, you’ll get back nothing.

• Bet \$1 on Moon and \$1 on Jeb. With probability 0.7, Moon will win and you’ll get back \$2. With probability 0.2, Jeb will win, and you’ll get back \$11. If they both lose, you’ll get back nothing.

1. What’s the expected value of each bet? What action would a risk-neutral bettor choose? Solution:

Expected Values:

• Bet \$2 on Moon: $. 7 \cdot \mathsf { U } ( 2 ) + . 3 \cdot \mathsf { U } ( - 2 ) = \mathtt { 0 } . 8$

• Bet \$2 on Jeb: $. 2 \cdot \mathsf { U } ( 2 0 ) + . 8 \cdot \mathsf { U } ( - 2 ) = 2 . 4$

• Bet \$1 on Moon and \$1 on Jeb: $. 7 \cdot \mathsf { U } ( \mathtt { 0 } ) + . 2 \cdot \mathsf { U } ( \mathtt { 9 } ) + . 1 \cdot ( - 2 ) = \mathsf { 1 } . 6$

So a risk-neutral bettor would choose the second option, putting all their money on Jeb.

2. Now, consider a risk-averse bettor, whose utility function for money is

$$
U (x) = \sqrt {x + 2 0}.
$$

What are the expected utilities of each bet? What action would that person choose?

## Solution:

Expected utilities:

• Bet \$2 on Moon: 4.56

• Bet \$2 on Jeb: 4.66

• Bet \$1 on Moon and \$1 on Jeb: 4.63

This person would choose the second option, as well, but it’s very close to the other options. If we changed the utility function to be $\mathsf { U } ( \mathsf { x } ) = \sqrt { \mathsf { x } + 3 }$ , the values for the three bets are now 1.87, 1.76, and 2.01. So now, we’d prefer option 3.

3. How do the outcomes of the previous parts relate to investment strategy?

## Solution:

Investment straegy should differ depending on a person’s utility function.

It’s common to reduce risk by simultaneously betting on a variety of different options. This is called “hedging ones’ bets,” and it’s why, when we’re really risk averse (the last utility function simulates having only \$3 in our pockets), we hedge.
